CO2 Tracker 🌍

A modern web application built to track, manage, and analyze CO₂ emissions through an interactive and user-friendly dashboard. The project helps users monitor carbon emission data and promotes environmental awareness using real-time data management features.

🚀 Features
Track and monitor CO₂ emissions
Interactive and responsive user interface
Real-time data storage and management
User-friendly dashboard for analysis
Secure backend integration using Supabase
🛠️ Tech Stack
React
TypeScript
Tailwind CSS
Supabase
Vite
📂 Project Structure
src/ – Main application source code
components/ – Reusable UI components
supabase/ – Backend and database configuration
public/ – Static assets and files
⚡ Installation & Setup
Clone the repository
git clone https://github.com/SohamRHiremath/co2-tracker.git
Navigate to the project folder
cd co2-tracker
Install dependencies
npm install
Start the development server
npm run dev
